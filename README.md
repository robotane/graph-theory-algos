# graph-theory-algos

Quelques algorithmes de théorie des graphes implémentés en Python.

## Contenu

- `ParcoursEnProfondeur.py` — parcours en profondeur (DFS)
- `PlusCourtChemin.py` — recherche de plus court chemin
- `Tris.py` — algorithmes de tri
- `fonctionsDeBase.py` — structures et fonctions de base pour la représentation des graphes
- `test.py` — tests

Projet réalisé dans un cadre académique (théorie des graphes).
